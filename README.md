# KRAMA

KRAMA es una página web para compartir publicaciones y ordenar el contenido por publicaciones.

## Estado actual

El proyecto tiene HTML y estilos CSS, más tarde se agregará JavaScript

## Características

- Mostrar publicaciones de ejemplo.
- Organizar publicaciones por categorías.
- Navegar entre las secciones.
- Perfil de usuario.
- Diseño adaptable a computadoras y celulares.

## Archivos principales

- `index.html`: estructura de la página.
- `styles.css`: diseño y apariencia de KRAMA.
- `.gitignore`: archivos que no se incluyen en el control de versiones.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git
