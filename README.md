# KRAMA

KRAMA es una página web en donde puedes compartir publicaciones y organizar el contenido por diferentes categorías.

## Estado actual

Actualmente el proyecto cuenta con la estructura HTML y los estilos CSS. La parte de JavaScript se agregará posteriormente para darle interactividad a la página.

## Características

- Crear y mostrar publicaciones.
- Organizar publicaciones por categorías.
- Navegación entre las diferentes secciones.
- Diseño adaptado a computadoras y celulares.
- Interacciones mediante JavaScript en futuras versiones.

## Archivos principales

- `index.html` — estructura de la página.
- `styles.css` — diseño y apariencia de KRAMA.
- `.gitignore` — archivos que no se incluyen en el control de versiones.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
