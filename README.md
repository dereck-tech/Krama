# KRAMA

KRAMA es una página web ficticia para compartir publicaciones y organizar el contenido por categorías.

## Estado actual

El proyecto cuenta con una estructura HTML y estilos CSS. La interactividad con JavaScript se agregará en una etapa posterior.

## Características

- Mostrar publicaciones de ejemplo.
- Organizar publicaciones por categorías.
- Navegar entre las secciones.
- Perfil de usuario.
- Diseño adaptable a computadoras y celulares.

## Archivos principales

- `index.html`: estructura de la página.
- `styles.css`: diseño y apariencia de KRAMA.
- `.gitignore`: archivos que no se incluyen en el control de versiones.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git
