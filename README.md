# KRAMA

KRAMA es una página web en donde se pueden compartir las publicaciones que quieras, conectar con los demás y personalizar quién eres.

## Estado actual

Mi página tiene HTML, CSS (colores beige y beige claro) y funciones muy básicas de JavaScript (dar like, poder editar perfil, poder desplazarse entre las publicaciones, etc)

## Características

- Mostrar publicaciones
- Publicaciones por Categorias
- Navegar por cada sección
- Perfil del Usuario
- Diseño adaptado a computadoras y celulares.

## Archivos principales

- `index.html`: estructura de mi página.
- `styles.css`: diseño y apariencia de KRAMA.
- `.Script.js`: funciones de mi página.

## Tecnologías

- HTML
- CSS
- JavaScript (node.js y Visual Studio Code)
- Git
